# Attendance Recovery Computation

## About the Project
The Attendance Recovery Computation system is a Python-based program designed to calculate students' attendance percentages and determine the minimum number of additional classes required to achieve the required attendance percentage.

## Objectives
- Calculate the current attendance percentage.
- Check whether a student meets the attendance requirement.
- Determine the minimum additional classes required.
- Display the final attendance percentage.

## Concepts Used
- Variables and data types
- Arithmetic operators
- Conditional statements
- While loop
- User input and output

## How the Program Works
1. The user enters the number of classes attended.
2. The user enters the total number of classes conducted.
3. The required attendance percentage is entered.
4. The program calculates the current attendance percentage.
5. If attendance is below the requirement, a loop calculates the additional classes needed.
6. The final result is displayed.

## Conclusion
This project demonstrates how Python can be used to calculate attendance percentages and determine attendance eligibility using conditional statements and loops.
